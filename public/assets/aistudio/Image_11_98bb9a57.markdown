## Brand & Style

The design system establishes a high-performance, dark-first developer atmosphere tailored for AI-orchestrated code intelligence. It blends the structural precision of technical workspaces with the fluid, kinetic responsiveness expected by modern engineers.

### Brand Personality & Core Values
- **Technical Rigor:** Crisp hierarchy, uncompromising information density, and instant legibility designed for complex repository navigation and deep debugging workflows.
- **Cognitive Clarity:** Distraction-free obsidian workspaces that elevate syntax, metadata, and artificial intelligence insights without visual fatigue.
- **Electric Precision:** Subtle photonic accents and hairline borders that direct focus instantly to agent actions, diff traces, and contextual source citations.

### Visual Style
A fusion of **Modern Developer Minimalist** and **Subtle Photonic Glass**. The interface relies on dark obsidian layered surfaces, micro-hairline borders (1px with subtle alpha channels), precise 4px spatial units, and restrained, directional glow halos that activate only during real-time AI indexing and context generation.

## Colors

The palette is engineered exclusively around dark-mode mechanics, balancing obsidian black canvas depths with high-chroma electric violet and cyber blue drivers.

### Surface Architecture
- **Base Canvas (`#0B0D13`):** The foundational substrate for window framing, application shells, and command palettes.
- **Layer 01 - Canvas Inset (`#0F121C`):** Code editor canvases, terminal backing, and inactive viewports.
- **Layer 02 - Surface Default (`#151926`):** Standard structural elements, persistent panels, and breadcrumb trails.
- **Layer 03 - Surface Raised / Cards (`#181D2D`):** Interactive cards, code review diff containers, inspect drawers.
- **Layer 04 - Surface Overlay / Modals (`#1E2438`):** AI reasoning popovers, command menus, and floating toolbars.

### Hairlines & Boundaries
- **Hairline Subtle (`rgba(59, 72, 111, 0.25)`):** Default divider lines between secondary panels and list items.
- **Hairline Border (`#2A324B`):** Standard structural card borders and input boundaries.
- **Hairline Focused (`rgba(139, 92, 246, 0.5)`):** Dynamic boundary accent indicating active context, active git branches, or focused inputs.

### Semantic & Highlighting Roles
- **Electric Violet (`#8B5CF6`, `#7C3AED`):** AI reasoning, autonomous actions, pull-request synthesis, primary buttons.
- **Radiant Cyber Blue (`#3B82F6`, `#256FEE`):** Active repository branches, search filter selections, active navigation links.
- **Emerald Pulse (`#10B981`):** CI/CD pipeline passing, test coverage verification, code additions.
- **Cyan Spark (`#06B6D4`):** Live indexing, real-time semantic search highlights, token consumption metrics.
- **Amber Warning (`#F59E0B`):** Code smells, breaking change alerts, rate limit thresholds.
- **Rose Destructive (`#EF4444`):** Merge conflicts, syntax errors, deleted code blocks.

### Typography Neutral Continuum
- **Text Crisp (`#F8FAFC`):** Primary headings, current code line, primary values.
- **Text Standard (`#CBD5E1`):** Body narrative, documentation text, markdown replies.
- **Text Muted (`#94A3B8`):** Filenames, commit hashes, table labels, inactive icons.
- **Text Subdued (`#64748B`):** Line numbers, metadata timestamps, decorative hints.

## Typography

Typography balances systematic, legible grotesque forms for conversation and documentation against an unforgiving monospaced font for code exploration and telemetry.

### Font Pairings
- **Primary Interface (`Inter`):** Handles narrative, conversational prompts, dashboard analytics, and structural navigation. Inter's optical neutrality guarantees zero visual drag across dense interfaces.
- **Technical & Syntactic (`JetBrains Mono`):** Dedicated to syntax presentation, directory pathways, inline variable references, git hashes, terminal views, and system tags.

### Micro-Typographic Rules
- Always render commit hashes, semantic tags, and file trees in `label-sm` or `code-sm` with tabular numerals enabled (`font-variant-numeric: tabular-nums`).
- Code blocks must respect absolute line-height synchronization with line gutter counters to eliminate misalignment during long diff comparisons.
- AI conversation bubbles employ `body-md` for natural readability, while embedded code references immediately drop into `code-md` nested blocks.

## Layout & Spacing

The layout philosophy uses a disciplined **modular multi-pane structure** built on a strict 4px/8px coordinate plane.

### Pane & Grid Architecture
- **Desktop (>= 1280px):** Three-tier operational split view:
  1. *Left Navigation / Explorer Pane:* Fixed 260px collapsible panel.
  2. *Center Workspace / Code Stream:* Flexible content viewport spanning remaining canvas width.
  3. *Right Copilot / Context Drawer:* Dockable 380px panel or floating overlay.
- **Tablet (768px - 1279px):** File explorer collapses to an icon rail (64px), central workspace claims primary viewport, and AI assistant converts to a sliding sheet.
- **Mobile (< 768px):** Single-column stacked mode. Sidebars tuck into bottom drawers or slide-in sheets. Command palettes convert to full-screen overlays.

### Spacing Principles
- Gaps between modular panels default to `space-sm` or `space-md` with 1px border dividers to maximize information density.
- Inner card padding follows `space-lg` (16px) for tight telemetry cards and `space-xl` (24px) for expansive AI response panels.
- Micro inline gaps (`space-xs`, `space-sm`) are strictly enforced between branch icons, pills, and copyable commit hashes.

## Elevation & Depth

This system intentionally eliminates traditional heavy drop shadows in favor of **tonal stepping, subtle glow halos, and hairline borders**.

### Hierarchy Levels
1. **Level 0 (Flat Canvas - `#0B0D13`):** Shell background, non-interactive backplates. Zero elevation.
2. **Level 1 (Card & Module Layer - `#181D2D`):** Bound by `1px solid rgba(59, 72, 111, 0.25)`. No shadow during rest state.
3. **Level 2 (Active / Hovered Component):** Maintained on `#1E2438` with an activated border (`rgba(139, 92, 246, 0.35)`) and an ultra-diffused atmospheric shadow: `box-shadow: 0 4px 20px -2px rgba(11, 13, 19, 0.8), 0 0 12px -2px rgba(139, 92, 246, 0.15)`.
4. **Level 3 (Command Palette & AI Overlays):** Background uses `#1E2438` with 90% opacity paired with `backdrop-filter: blur(16px)` and perimeter ring `1px solid rgba(59, 72, 111, 0.4)`. Drops an expansive shadow: `box-shadow: 0 24px 48px -12px rgba(0, 0, 0, 0.6)`.

### Lighting & Photonic Accents
- AI generation triggers a kinetic border glow that sweeps horizontally using a linear gradient containing `#8B5CF6`, `#3B82F6`, and `#06B6D4`.
- Highlighting code snippets utilizes radial focus gradients positioned under the cursor or active token stream.

## Shapes

The geometric personality features precise, contemporary corner radii that soften dense technical layouts without feeling informal.

### Corner Radii Guidelines
- **Outer Shells & Modular Cards:** Use `rounded-xl` (1.5rem / 24px) or `rounded-lg` (1rem / 16px) for card wrappers, modals, and preview panes.
- **Interactive Controls (Inputs, Buttons, Dropdowns):** Built with default standard roundedness (0.5rem / 8px) for balanced cursor targeting.
- **Micro Tokens (Badges, Git Tags, Commit Pills):** Use complete pill radii (`9999px` or 1rem) for branch markers and status dots.
- **Embedded Code Surfaces:** Syntax viewports and code diff rows maintain a tighter 6px to 8px radius to preserve horizontal scanning rhythm.

## Components

### Buttons
- **Primary (AI & System Actions):** Background `linear-gradient(135deg, #8B5CF6 0%, #7C3AED 100%)`, text `#F8FAFC`, font weight 500. Hairline top highlight: `inset 0 1px 0 rgba(255, 255, 255, 0.2)`. Focus: 2px ring `#8B5CF6` with 2px offset in `#0B0D13`.
- **Secondary (Standard Action):** Background `#181D2D`, border `1px solid #2A324B`, text `#F8FAFC`. Hover: Background `#1E2438`, border `rgba(139, 92, 246, 0.4)`.
- **Ghost / Icon (Toolbars, Window Controls):** Transparent background, text `#94A3B8`. Hover: Background `#181D2D`, text `#F8FAFC`.

### Form Inputs & Command Palette
- **Input Fields:** Background `#0F121C`, border `1px solid #2A324B`, placeholder `#64748B`, text `#F8FAFC`. On focus: Border `#8B5CF6`, subtle ambient glow `0 0 0 3px rgba(139, 92, 246, 0.15)`.
- **Global Command Menu (`⌘K`):** Centered overlay, width 640px, rounded `rounded-xl`. High-translucency obsidian backdrop blur (`16px`). Integrated input with leading search icon and trailing key combo badges (`⌘`, `K`).

### Chips, Git Badges & Commit Pills
- **Branch Badges:** Background `rgba(59, 130, 246, 0.1)`, border `1px solid rgba(59, 130, 246, 0.25)`, text `#3B82F6`, font `JetBrains Mono` at `label-sm`. Accompanied by git branch icon.
- **Commit Hash Pill:** Compact monospaced tag, background `#151926`, text `#94A3B8`, interactive copy button appearing on hover.
- **Status Badges:** Featuring a 6px status indicator light: Emerald for passing, Amber for review required, Rose for failed checks.

### Cards & Code Diff Containers
- **Card Shells:** Surface `#181D2D`, border `1px solid rgba(59, 72, 111, 0.25)`, radius `rounded-lg` or `rounded-xl`.
- **Diff Containers:** Split or unified view with gutter line counters in `#64748B`. Addition lines: Background `rgba(16, 185, 129, 0.08)`, border-left `2px solid #10B981`. Deletion lines: Background `rgba(239, 68, 68, 0.08)`, border-left `2px solid #EF4444`.

### AI Conversational Bubbles & Source Citations
- **User Prompt Bubble:** Subtle elevated slate `#1E2438` aligned to panel end, crisp border `1px solid #2A324B`.
- **RepoMind Agent Bubble:** Transparent canvas aligned to start, punctuated with an electric violet spark indicator. Markdown content parsed cleanly with code blocks highlighted in `#0F121C`.
- **Citations / Context Accordions:** Monospaced expandable pills listing `filepath:line_number` (e.g., `src/auth/jwt.rs:42-58`). Hover displays an instant floating preview of relevant AST context.

### File Explorer Tree
- Indentation steps of 12px per hierarchy tier with subtle dotted guide rails in `rgba(100, 116, 139, 0.2)`.
- Folder open/closed states accompanied by file-type specific mini icons, highlighting modified or untracked files in amber or emerald.
